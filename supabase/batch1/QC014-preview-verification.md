# QC-014 controlled Preview verification candidate

This temporary route is exclusively for `audit/qc-batch1-isolated`. It requires Vercel Preview, SSO protection, a temporary operator token supplied in the `x-adp-qc-probe` header, a short UTC expiry, exact ADP-Rehearsal URL/ref and branch origin, disabled Mux IDs and secrets, and both playback flags false. Unauthorized requests receive 404; authorized configuration/key failures return a sanitized code. All responses use `private, no-store`.

Keep automatic Preview deployments paused. Before a single manual deployment, check the pinned Git SHA, the branch-specific Supabase URL/ref, public and sensitive keys, exact Preview alias, disabled Mux IDs and absence of Mux secrets, playback flags, SSO, and that Production still points to main. Set `ADP_QC_PROBE_TOKEN` to a fresh random value in protected branch settings, `ADP_QC_PROBE_ENABLED=true`, and `ADP_QC_PROBE_UNTIL` to no more than 15 minutes after the planned probe. Do not put the token in a URL, source, command log or report.

Deploy manually with the Git source pinned to the reviewed SHA and explicit Preview target. Verify returned deployment SHA and target before sending requests. A controlled GET to `/api/diagnostics/qc014` with the token header returns only `expectedProjectRef`, `ok`, and `code`. A successful `ADP-QC014-OK` means the effective service-role credential was accepted by the hard-coded Rehearsal endpoint for a read-only Release 121 query. It does not reveal the key or prove provenance if multiple projects share a JWT secret. Try a missing/wrong header (404) and review runtime logs for sanitized codes and unexpected writes. Never send the probe to Production.

Immediately set `ADP_QC_PROBE_ENABLED=false`, expire the timestamp, and replace the operator token with a disabled placeholder after verification. Keep automatic Previews paused. Remove this route and its variables in a separately reviewed cleanup commit before allowing normal Preview activity. If any isolation check fails, stop; do not run QC-002 fixtures or QC-006 migrations.
